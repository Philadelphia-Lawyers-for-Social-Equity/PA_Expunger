# Security Policy

PA Expunger is a pre-MVP project maintained by volunteers. It handles sensitive
criminal-record information, so please report suspected security vulnerabilities
privately.

## Report a vulnerability

Email [plseteam@codeforphilly.org](mailto:plseteam@codeforphilly.org).
Please do not disclose vulnerabilities in public GitHub issues, pull requests,
or public Slack channels.

Include the following information, if available:

- The affected version or commit and the part of the application involved.
- Steps to reproduce the issue, using synthetic or anonymized examples.
- The potential impact and any conditions needed to exploit the issue.

Do not include real client records, Social Security numbers, passwords, tokens,
or other credentials in your report. If sensitive material is needed to
investigate, describe what it contains so we can coordinate how to share it
privately.
